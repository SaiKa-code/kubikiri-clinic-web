# クビを回避せよ！！ ～病院受付シミュレーション～ 公式サイト

高難易度・病院受付シミュレーションゲーム「クビを回避せよ！！（首切クリニック）」の販促用ランディングページです。

- 制作: **SaiKa工房**
- 公開: GitHub Pages（`main` ブランチ / ルート）

## ローカルで確認する

このリポジトリは静的サイトです。`index.html` をブラウザで開くだけで確認できます。

```
# 簡易サーバーで確認する場合（任意）
python -m http.server 8000
# → http://localhost:8000
```

## スクリーンショットの差し替え

`index.html` の `#shots` セクションにあるプレースホルダー（`.shot`）を、実際のゲーム画面画像に置き換えてください。画像は `assets/` に配置します。
